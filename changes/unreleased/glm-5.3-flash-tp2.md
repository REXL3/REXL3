## Highlights

- GLM-5.3-Flash (EXL3 2.25 bits per weight, SAGE) on two GB10 nodes, tensor parallel, is now its own runtime unit (`glm-5.3/glm-5.3-flash-tp2`, runtime `glm53-flash-tp2-sage-2.25`): the model's full 1,048,576-token window, 1 slot, speculative decoding and prefix cache on, vision on (`glm53-flash-tp2-1m`, port 8950). SAGE is our own mixed-precision quantization method for EXL3. The method is not published. A fresh full gate chain on the release binary (engine 0.1.1, two GB10s) passed all 11 gates, including context needles at 131,072 to 1,048,576 tokens (16 of 16, each answered again from the cache) and chunked prefill equal to whole prefill on a 1,047,682-token prompt. Measured on that binary: 56.8 tok/s generation for one stream (median of 3 runs of 5 replies of 256 tokens, short context), prompt speed 1,133 tok/s at 524,309 tokens and 980 tok/s at 1,044,466 tokens (cold prompts, median of 3 runs; the full-window prompt takes about 18 minutes). Q200 184 of 200 (92.0%) at reasoning effort `xhigh`, greedy, a 65,536-token budget, one client worker remote from the leader; 3 text replies ran to the budget and count as incorrect. The floors are this pack's v0.1.0 two-node scores minus two cases per suite. Every reply thinks; thinking cannot be switched off. Details and methods in `docs/packs/glm-5.3-flash-tp2.md`. Added by #PR.

## Known issues

- GLM-5.3-Flash two-node: the HTTP endpoint listens on the leader's address from the site file, not on `127.0.0.1`, and the server has no API key. Run it only on a private, trusted network, or behind a firewall or an SSH tunnel. The pack sheet states this; thanks to @Blackwellboy for the report in #114.
