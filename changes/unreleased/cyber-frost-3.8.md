## Highlights

- **CYBER-FROST-3.8** (EXL3 3.35 bits per weight, SAGE; the Qwen3.8-Flash-Next architecture), new in this release, version 1 (`cyberfrost-3.8-single-262k`: one GB10, 262,144 tokens, 2 slots, port 8899, MTP speculation and prefix cache on, image input off), qualified on engine 0.1.3 with a full gate chain. It pins pack `vcruz305/CYBER-FROST-3.8-SAGE-REXL3-3.35bpw` at revision `33be4227`.
  - Gates: all passed. Exactness 68 of 68, including chunked prefill equal to whole prefill at five prompt lengths up to 261,120 tokens, with 256- and 512-token chunks. Context needles 8 of 8 at 131,072 and 262,144 tokens.
  - Speed on the release binary: 63.0 tok/s generation for one stream (median of 3 runs, each the median of 5 streamed replies of 256 tokens, short context). Prompt speed 1,146 and 1,105 tok/s at 50% and 100% of the window (cold prompts, median of 3 runs). Lowest free memory 36.4 GiB during those runs, with no swap. Boot to ready took 15.1 s.
  - Q200 178 of 200 (89.0%) at reasoning effort `xhigh`, greedy, a 65,536-token text budget and 8,192 for BFCL, one client worker on another host. 6 text replies ran to the budget with no answer and count as incorrect. GSM8K 77/80, HumanEval 39/40, IFEval 34/40, hard reasoning 19/20, BFCL hard-20 9/20.
  - This is the runtime's first version. Its floors were set from this run at two cases below each suite's score. Hard reasoning was graded by an independent reviewer, who passed four answers that give the correct value without working, because those questions ask only for the value. The Q200 run and its requirements file use a later revision of the evaluation tools; the engine and the binary are those of the v0.1.3 engine commit `0c8bc43c`.
  - One qualifier row was rerun with a corrected probe: prefix cache, cold versus warm. The probe gave the reply 32 tokens, which this always-thinking model spends inside its reasoning, so the first attempt failed. The failed attempt is kept in the sealed evidence.
  - The runtime's `profile.json` also lists the opt-in choice `cyberfrost-3.8-dflash-single-262k`, which is **not part of v0.1.3**. Its DFlash2 draft was trained for Qwen3.8-Flash-Next, not this model, and on Qwen3.8-Flash-Next it is not faster than MTP (69.5 against 71.7 tok/s in this release's runs, above). Use the default choice.
