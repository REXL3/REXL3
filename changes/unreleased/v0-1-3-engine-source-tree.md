- The engine source tree on `main` now matches the v0.1.3 engine commit `0c8bc43cf37318210544cd54da80b5b0bb6ccd76` (tree `5776f1387f040f3c0762c42dc33214512e1194db`). That tree covers `crates/`, `third_party/`, `testdata/`, `Cargo.toml`, `Cargo.lock`, `rust-toolchain.toml`, `rustfmt.toml`, `.cargo/`, `SOURCE_BUILD.md`, `SOURCE_IDENTITY.json`, `THIRD_PARTY_NOTICES.md`, `tools/switch_registry.json` and the 18 cluster examples under `docs/examples/` that `SOURCE_IDENTITY.json` lists.
