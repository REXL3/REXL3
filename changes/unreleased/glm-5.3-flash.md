## Highlights

- GLM-5.3-Flash (EXL3 2.25 bits per weight, SAGE) version 2: the single-node profile (`glm53-flash-single`: one GB10, 262,144 tokens, 1 slot, port 8950, speculation and prefix cache on, vision on) requalified on engine 0.1.1 under the runtime's current id `glm53-flash-sage-2.25` (earlier `glm53-flash-2.25bpw-sm121`; the pack repository is now `r0b0tlab/GLM-5.3-Flash-EXL3-SAGE-2.25bpw`, same revision and files). SAGE is our own mixed-precision quantization method for EXL3. The method is not published. Doctor, lifecycle, capability, boundary, vision, exactness (68 of 68, including chunked prefill equal to whole prefill on a 261,120-token prompt), prefix cache and performance ran fresh on the release binary; context and quality are carried from version 1's sealed single-node qualification. Measured on the release binary: 38.9 tok/s generation for one stream (median of 3 runs of 5 streamed replies, short context), prompt speed 997 and 994 tok/s at 50% and 100% of the window (cold prompts, median of 3 runs), lowest free memory 9.9 GiB with no swap. Q200 (carried, reasoning effort `xhigh`): GSM8K 77/80, HumanEval 39/40, IFEval 37/40, hard reasoning 19/20, BFCL hard-20 12/20. The two-node profile is now its own runtime unit (`glm-5.3/glm-5.3-flash-tp2`). `MODEL.json` names the current id; version 1 stays in the tree under the earlier id. Details and methods in `docs/packs/glm-5.3-flash.md`. Added by #143.
