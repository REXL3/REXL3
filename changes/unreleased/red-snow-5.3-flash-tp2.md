## Highlights

- RED-SNOW-5.3-Flash (EXL3 4.91 bits per weight, SAGE; a GLM-5.3-Flash derivative) on two GB10 nodes, tensor parallel: 524,288-token window, 1 slot, speculative decoding with the pack's MTP layer, pool-page prefix cache and image input on (`redsnow-tp2-512k`, port 8952). SAGE is our own mixed-precision quantization method for EXL3. The method is not published. Measured on the release binary (engine 0.1.1, two GB10s): 34.5 tok/s generation for one stream (median of 3 runs of 5 replies of 256 tokens, MTP on, short context), prompt speed 1,097 tok/s at 262,337 tokens and 1,014 tok/s at 520,333 tokens (cold prompts, median of 3 runs). Q200 160 of 200 (80.0%) with thinking off, greedy text suites with an 8,192-token budget, one client worker remote from the leader; this score, the pack's own baseline, and the context gate were measured on the previous engine build and carried under a 51-case bit-identity record (token-identical outputs, including a 523,135-token full-window request). Thinking is off unless a request sets `enable_thinking`. Details and methods in `docs/packs/red-snow-5.3-flash-tp2.md`.

## Known issues

- RED-SNOW-5.3-Flash two-node: with thinking off the model may answer a tool request from memory instead of calling the tool (a replay of three such cases with thinking on called the right tool); some replies after a tool call start with reasoning text that ends in a closing think tag.
