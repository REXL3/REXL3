## Known issues

- **DeepSeek-V4.1-Flash-1017: the pinned pack revision is gone from Hugging Face.** Both DeepSeek-V4.1 runtimes (`deepseek-v4.1-flash-1017` v1, single node, and `deepseek-v4.1-flash-1017-tp2` v1, two nodes) pin `vcruz305/DSV4.1-Flash-1017-SAGE-REXL3-1.55bpw` at revision `cba79c67582950ea44a4a449b3bb85b800748a35`. The repository's history was rewritten, so the Hub now answers 404 for that revision and `setup --accept-model-download` fails with `MODEL_DOWNLOAD_FAILED`. The repository's only revision, `c40cf25cc3148bae95ac27483505c883840bf8a7`, holds the same files: all 24 files in `model.lock.json` have the same size and SHA-256 there (the 19 large files compared by the Hub's LFS SHA-256, the 5 small files hashed after download). It only adds `README.md`, `LICENSE` and `.gitattributes`, which the runtime accepts beside the pack.
- **Workaround:** download `c40cf25c` yourself and point the runtime at it with the `model_dir` site field. The runtime checks every file against the sealed `model.lock.json` (sizes, SHA-256, index and the engine's fingerprint), not the revision name, so this is the same check a managed download gets. See the pack sheets for the commands. Single node: one copy. Two nodes: a complete copy on each node, named by `nodes.leader.model_dir` and `nodes.follower.model_dir`.
- Reported by @Blackwellboy in #128, who also hashed the 24 files first. Added by #148.
