## Highlights

- Ling-3.1-Flash-1019 (EXL3 1.51 bits per weight, SAGE) is new: one GB10, the 262,144-token window, 1 slot, speculative decoding with the pack's MTP head, prefix cache on, text only (`ling-3.1/ling-3.1-flash-1019` version 1, runtime `ling31-flash-1019-sage-1.51`, profile `ling31-single-262k`, port 8889). SAGE is our own mixed-precision quantization method for EXL3. The method is not published. A fresh full gate chain on the release binary (engine 0.1.1, one GB10) passed all 11 gates, including context needles at 131,072 and 262,144 tokens (8 of 8, each answered again from the cache) and chunked prefill equal to whole prefill up to a 261,369-token prompt. Measured on that binary: 27.1 tok/s generation for one stream (median of 3 runs of 5 streamed replies of 256 tokens, short context), prompt speed 341.8 tok/s at 131,109 tokens and 223.3 tok/s at 260,148 tokens (cold prompts, median of 3 runs; the full-window prompt takes about 19.5 minutes); the floors are 20, 250 and 150 tok/s. Q200 179 of 200 (89.5%) with thinking on, text suites at temperature 0 with a 32,768-token budget, one client worker on the same host; 8 text replies ran to the budget and count as incorrect. The floors equal this run's scores minus two cases per suite. Thinking is off unless a request sets `chat_template_kwargs.enable_thinking` to true. Details and methods in `docs/packs/ling-3.1-flash-1019.md`. Added by #153.

## Known issues

- Ling-3.1-Flash-1019: With `chat_template_kwargs.enable_thinking` false, the model still writes reasoning text and a stray `</think>` into the answer (model behaviour; maintainer-granted thinking exception, expires 2026-12-31). Workaround: keep thinking on, or strip everything up to the last `</think>` from the content. The release qualifier's context, prefix-cache, tool, speculation and smoke checks ran with thinking on under that exception.
- Ling-3.1-Flash-1019: `launch.sh start` re-hashes the ~107 GiB pack just before boot; the page cache this leaves can make the engine plan its KV cache below the 262,144-token window and refuse to start. Workaround: free the file cache before start (for example `sync; echo 1 | sudo tee /proc/sys/vm/drop_caches`). A launcher fix ships in v0.1.2.
